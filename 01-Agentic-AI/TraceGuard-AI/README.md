# TraceGuard AI

AI-Powered Security Log Analyzer using LLM Tool Calling.

## Project Overview

TraceGuard AI is a web-based security log analysis
application built using Python and Flask.

It uses a Large Language Model (LLM) with tool-calling
capabilities to investigate security logs, identify
suspicious activity, and generate security reports.
