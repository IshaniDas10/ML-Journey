# Agentic AI

## Overview

This section documents my one-day introduction to Agentic AI, focusing on understanding how AI agents work, how they interact with tools, and how they perform tasks autonomously.

## Learning Objectives

- Understand what AI agents are.
- Understand the difference between an AI model and an AI agent.
- Learn about context and context engineering.
- Understand tool calling and tool execution.
- Explore the agent loop and how coding agents work.
